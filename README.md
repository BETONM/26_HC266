## 1. 프로젝트 개요

### 1-1. 프로젝트 소개

- **프로젝트 명:** [Lab Assistant Robot] Physical AI 화학 실험 어시스턴트 로봇
- **프로젝트 정의:** 온톨로지 기반의 Physical AI 화학 실험 어시스턴트 로봇으로, 화학 실험 과정에서 필요한 다양한 작업을 수행하고, 실험자의 안전을 보장하며, 효율적인 실험 환경을 제공하는 지능형 로봇 시스템

### 1-2. 개발 배경 및 필요성

화학 실험실에서는 용매 혼합, 분말 계량, 반응물 투입처럼 반복적이고 정밀한 작업이 많아 인적 오류가 생기기 쉽습니다. 또 유해 물질이나 고온·발열 반응을 다루는 실험에서는 연구자가 위험 환경에 직접 노출됩니다. 기존 실험 자동화 장비는 특정 공정이나 단일 장비 제어에 머물러, 실험 설계부터 수행·기록까지 하나의 흐름으로 처리하기 어렵습니다. 그래서 로봇이 위험하고 반복적인 작업을 맡고 연구자는 실험 설계와 판단에 집중할 수 있는 시스템이 필요합니다.

### 1-3. 프로젝트 특장점

- **특장점 1:** 레일 위의 듀얼 로봇팔로 작업 공간을 확장하고, 양팔이 주작업·보조작업을 나눠 수행
- **특장점 2:** 온톨로지로 실험을 탐색하고, 챗봇 중심 UI로 정해진 실험 목록에 얽매이지 않고 자유롭게 실험을 구성
- **특장점 3:** 상위 AI Agent(실험 계획·상태 판단)와 ACT 기반 행동 생성(로봇 조작)을 분리한 계층형 Physical AI 구조
- **특장점 4:** AI Vision과 pH·온도·전도도 등 다중 센서로 실험 상태를 실시간 판단하는 폐루프 제어
- **특장점 5:** 실험 데이터와 Agent 판단 근거를 DB에 저장하고 보고서(PDF/CSV)를 자동 생성해 재현성 확보

### 1-4. 주요 기능

| 주요 기능 | 설명 |
|----------|------|
| 온톨로지 기반 실험 탐색 | 온톨로지로 시약·실험기구·반응·안전 정보의 관계를 탐색해 수행 가능한 실험을 찾고 추천 |
| 챗봇 기반 실험 구성 | 정해진 실험을 고르는 방식이 아니라 챗봇과 대화하며 실험·시약·용량을 자유롭게 구성하고, LLM Agent가 Task/Subtask로 분해해 안전 규칙과 대조해 검증 |
| 듀얼 로봇팔 수행 | ACT 기반 모방학습 정책으로 파지·이동·붓기·교반 등 실험 동작을 수행 |
| 비전·센서 모니터링 | 6D 자세 추정으로 실험기구를 인식하고 pH·온도·전도도·색상 변화를 계측 |
| 실시간 대시보드 | 센서값·추이 그래프·카메라 영상·로봇 상태를 표시하고 비상 정지(E-STOP) 지원 |
| 자동 보고서 생성 | 실험 요약, 센서 추이, 색상 변화 타임라인을 정리해 PDF/CSV로 내보내기 |

### 1-5. 기대 효과 및 활용 분야

**기대 효과**

- 유해 물질·고온 실험에서 연구자의 직접 노출을 줄여 안전성 향상
- 반복 조작과 수기 기록을 줄이고, 실험 데이터의 추적성과 재현성 확보
- 오픈소스 로봇, 저가 센서, 3D 프린팅 그리퍼로 소규모 연구실·교육기관에서도 도입 가능

**활용 분야**

- 교육기관 및 대학 실험실의 실험 자동화 실습 플랫폼
- 연구실 반복 실험(pH·전도도 등 측정) 자동화
- 스마트 실험실·원격 실험 환경

### 1-6. 기술 스택

| 구분 | 기술 스택 |
|------|----------|
| **프론트엔드** | React, TypeScript |
| **백엔드** | Python, FastAPI |
| **AI / ML** | PyTorch, LeRobot(ACT 모방학습), OpenCV, YOLO, ArUco, FoundationPose |
| **LLM / Agent** | LangGraph, OpenAI API |
| **데이터베이스** | SQLite, Neo4j(온톨로지) |
| **로봇 / 하드웨어** | OMX-AI Manipulator(DYNAMIXEL) 2대, 리니어 스테이지, PP 커스텀 그리퍼, Raspberry Pi 4, RealSense D435, pH·전도도 센서, 열화상 카메라 |
| **통신 / 인터페이스** | ROS2 Humble, RS485/USB, Wi-Fi/Ethernet |
| **배포 및 관리** | Ubuntu 22.04 LTS, Raspberry Pi OS, GitHub, Jira, Notion |

**동작 과정**

1. 사용자가 챗봇 UI에서 대화하며 실험을 구성하고(온톨로지로 실험 탐색), 시약·용액량을 설정
2. LLM Agent가 실험 절차를 설계하고, 시약 조합·용량을 안전 규칙으로 검증
3. 듀얼 로봇팔이 시약 이동·용액 투입·교반 등을 수행
4. 센서와 카메라가 pH·온도·색상 등을 측정하고, 대시보드에 실시간 표시하며 Agent가 다음 행동을 판단
5. 실험 종료 후 결과 보고서(PDF/CSV)를 생성하고 이력을 저장
